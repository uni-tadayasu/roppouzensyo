# 六法書架

憲法・民法・商法・刑法・民事訴訟法・刑事訴訟法を、検索、マーカー、用語、判例、男女の読み上げとともに参照できる日本語の法令サイトです。

## GitHub Pagesで公開

1. ZIPを展開します。
2. 新しいGitHubリポジトリを作り、展開した中身の `docs`、`scripts`、`.github`、`README.md`、`.gitignore` をリポジトリ直下に入れます。ファイルサイズや隠しフォルダを扱いやすい GitHub Desktop または git でのアップロードを推奨します。GitHubのWeb画面でアップロードする場合は、`.github/workflows/pages.yml` と `docs/.nojekyll` も反映されたことを確認してください。
3. リポジトリの **Settings → Pages → Build and deployment → Source** で **GitHub Actions** を選びます。
4. **Actions → 六法書架を公開・更新 → Run workflow** から既定ブランチを実行します。完了したら **Settings → Pages** に表示されるURLを開きます。

公開・更新は GitHub 内で完結します。GitHub PagesのURLに合わせて、ワークフローがOGP画像の公開URL、canonical、サイトマップを設定します。

## 法改正を反映する

GitHubの **Actions → 六法書架を公開・更新 → Run workflow** を選びます。現行施行版をe-Govから取得して再公開します。取得に失敗したときは、現在公開している版をそのまま閲覧できます。初回公開からやり直す場合は、公開設定でソースを選択したあとにワークフローを再実行します。

閲覧者はサイトの **法令を更新** で公開版を取り込めます。条文の個別解説や判例データはそれぞれ独立して管理しており、e-Govの更新で自動的に編集されるのは法令原文・全文版HTML・関連メタデータです。

## 閲覧とオフライン保存

- PCではマーカーモードでドラッグし、スマホでは指でなぞります。端末にマーカーが残ります。
- 法律用語は二重の下線、熟語は一重の下線です。用語、条文、項・号、解説、収録判例の内容を読み上げられます。
- 初めにオンラインで **オフライン保存** を完了してください。以降は通信なしで収録内容の検索・閲覧と男女の読み上げを利用できます。公式サイトへのリンクは通信が必要です。ブラウザのサイトデータを消去すると、ダウンロードした版とマーカーも消えます。
- 端末で確認するときは、展開フォルダで `python3 -m http.server 8000 --directory docs` を実行し、`http://localhost:8000/` を開きます。HTTPSのGitHub Pagesを使う場合にこの操作は不要です。

## 収録範囲とデータ

法令原文はe-Gov法令検索の現行施行版です。個別の条文解説と自動作成した概要を区別して表示します。判例は公開資料を収録しています。自動対応付けや自動抽出の結果と、編集した解説は画面で区別します。日本語の読み上げには自動音声の誤りが生じる場合があります。出典・第三者ライセンス・詳しい範囲は `docs/coverage.html` と各データの表示をご覧ください。判例コーパスは `python3 scripts/build-cases.py` で、指定された公開スナップショットから再生成できます。公式PDF由来の判決文を含めて再生成するには poppler-utils の `pdftotext` を用意してください。

## 読書を続ける

- **しおり**で条文や項の位置を100件まで保存できます。ホームの**前回の続きから読む**で前回の閲覧位置に戻れます。
- **文字サイズ・書体**は端末に保存されます。**集中して読む**で本文中心の表示に切り替え、画面下のボタンまたは Escape キーで戻せます。
- しおり・読書位置・音声設定は利用中のブラウザに保存します。他の端末には自動同期しません。

## 変更の検証と自動公開

`main` 向けのプルリクエストでは、読書・音声・オフライン更新の回帰テストと、公開ファイルの整合性検証が実行されます。`main` にマージすると、e-Govの現行施行版を取得し、検証に成功したファイルをGitHub Pagesへ自動公開します。取得や検証に失敗した場合は前の公開版が残ります。自動公開は `.github/workflows/pages.yml` が実行します。

ローカルでの確認:

```sh
node --test tests/*.test.mjs
python3 -m unittest discover -s tests -p 'test_*.py'
python3 scripts/build-site.py --output _site --site-url https://uni-tadayasu.github.io/roppouzensyo/
python3 scripts/validate-site.py _site
```

既に `_site` がある場合は、別の空の出力先を指定してください。検証はデータ構造・ファイル整合性・ローカルリンクを確認するもので、解説や法的解釈の正しさを認定するものではありません。
